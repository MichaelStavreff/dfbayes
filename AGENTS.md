# AGENTS.md — `dfbayes` (port of DFBA)

This repository is a Python port of the R package **DFBA 0.1.0**. It follows
the shared rules in the parent `r-ports` workspace, plus the package-specific
rules below.

A port is correct when it reproduces the R package's behavior, not when it looks
idiomatic on its own.

## Layout

```
upstream/DFBA/           pristine CRAN source, read-only, never edit
upstream/DFBA_0.1.0.tar.gz
src/dfbayes/             Python package (import name `dfbayes`)
tests/fixtures/generate.R  fixture generator; runs R's DFBA
tests/fixtures/*.json    golden outputs, committed
tests/                   pytest suite
DECISION.md              scope, name, NA/RNG policy, tolerances
COVERAGE.md              R source branch -> test map
CONTRIBUTING.md          dev setup, fixture policy, release process
justfile                 build/test/fixtures/clean
```

## Non-negotiables

- Never edit `upstream/`. If the port and R disagree, the port is wrong.
- Fixtures are generated by running R's DFBA 0.1.0. Do not hand-write expected
  values and do not copy values from another port.
- Do not loosen a numeric tolerance to make a test pass. Derive it from the
  fixtures and record the rationale in `DECISION.md`.
- Ports do not import or share code with each other.

## R semantics that bite here

- **`NA` is not `NaN`.** R's `is.na()` is TRUE for both. Inputs treat `None`
  and `NaN` as missing. Output NA is `None`; genuine `0/0` stays `NaN`.
- **Listwise vs pairwise deletion differs by function.** `dfba_sign_test` and
  `dfba_wilcoxon` drop pairs; `dfba_median_test` and
  `dfba_mann_whitney` drop each vector independently. Do not unify them.
- **`dfba_beta_descriptive` returns logical `NA`** for an undefined mode and
  HDI, not `NA_real_`. The port uses `None`.
- **1-based inclusive loops.** The Mann-Whitney/Wilcoxon ETI interpolation and
  the `I == 1` boundary are the usual off-by-one sites.
- **S4 list subclasses.** Field names *and order* are public API. The star
  concordance class has a duplicated `prob_interval` slot; the Python
  dataclass collapses it to one field, and `summary()` lists it in R order.
- **`drop = TRUE`, recycling, matrix layout.** `dfba_gamma` consumes a
  column-major R matrix/table; Python accepts a 2-D array and indexes it
  explicitly.

## RNG policy

R's Mersenne-Twister is not reproduced. Stochastic functions freeze the
narrowest R intermediate (`fomega`, `delta`/`delta0`) as a fixture and test the
deterministic downstream math exactly. The sampling wrapper uses numpy and is
covered by analytic-vs-Monte-Carlo and determinism tests. Do not claim numpy
sampling is equivalent to R's.

## Verification loop

1. `just fixtures` — regenerate JSON by running R's DFBA 0.1.0.
2. `just test` — run pytest against the fixtures.
3. If output differs, fix the port or document the divergence in
   `DECISION.md`; never weaken the fixture or tolerance.
